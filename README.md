# 基于状态机的交通灯控制器

这是一个使用 **Quartus II 13.1** 建立的层次化交通灯控制器工程。目标器件为 **Cyclone IV E EP4CE115F29C7**；顶层是 `Traffic_Light.bdf`，三个 Verilog 模块先生成符号，再在原理图中连接。

## 功能

| 状态码 | 主路 | 支路 | 持续时间 |
| ------ | ---- | ---- | -------: |
| `00`   | 绿灯 | 红灯 |    30 秒 |
| `01`   | 黄灯 | 红灯 |     5 秒 |
| `10`   | 红灯 | 绿灯 |    20 秒 |
| `11`   | 红灯 | 黄灯 |     5 秒 |

四个状态依次循环。`rst_n` 为低电平有效；复位后进入主路绿灯、支路红灯状态。

## 工程结构

| 文件                                       | 作用                         |
| ------------------------------------------ | ---------------------------- |
| `Traffic_Light.qpf`、`Traffic_Light.qsf`   | Quartus 工程和器件配置       |
| `Traffic_Light.bdf`                        | 顶层原理图，连接三个器件     |
| `timer_1s.v`、`timer_1s.bsf`               | 计数并产生 `tick_1s` 脉冲    |
| `traffic_fsm.v`、`traffic_fsm.bsf`         | 30/5/20/5 秒倒计时与状态转换 |
| `traffic_decoder.v`、`traffic_decoder.bsf` | 将两位状态码译成六路灯信号   |
| `docs/交通灯控制器全部Verilog代码.pdf`     | 三个模块的代码汇总           |

`clk` 和 `rst_n` 同时连接计时器与状态机；计时器的 `tick_1s` 接状态机；状态机的 `state_0`、`state_1` 接译码器；译码器输出主路和支路各三盏灯的控制信号。

## 打开与使用

1. 在 Quartus II 13.1 中打开 `Traffic_Light.qpf`。
2. 检查顶层实体为 `Traffic_Light`，目标器件为 `EP4CE115F29C7`。
3. 若开发板输入时钟为 **50 MHz**，保持 `timer_1s.v` 中的 `COUNT_MAX = 26'd49999999`。计数器从 0 数到 49,999,999，每 50,000,000 个时钟周期产生一个 `tick_1s` 脉冲。
4. 按开发板原理图为 `clk`、`rst_n` 和六路灯输出分配物理引脚，并核对 LED 是高电平还是低电平点亮。
5. 为 50 MHz 时钟添加 20 ns 周期的时序约束，再重新编译、仿真和下载。

原始工程曾成功生成 Quartus 编译输出，但**未设置具体板卡的物理引脚，也未提供有效的 SDC 时钟约束**。本仓库只保留可复现的工程源文件与代码文档，不包含编译缓存或已验证的上板结果；不能直接把生成的配置文件用于任意开发板。
